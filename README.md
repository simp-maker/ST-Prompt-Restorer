# 프롬프트 복원기 (Prompt Restorer) v3.0

SillyTavern 확장. 보낸 프롬프트를 전부 따로 저장하고, 다운로드 없이도 창 안에서 끝까지 볼 수 있게 해 줍니다. 월드인포 북·엔트리를 지울 때 지우기 직전 내용도 백업합니다.

## 설치
`SillyTavern/data/default-user/extensions/ST-Prompt-Restorer/`에 이 폴더를 두고 SillyTavern을 새로고침하세요.

## 여는 법
- 확장 서랍 → **프롬프트 복원기** → **복원기 창 열기**
- 마법봉 메뉴 → **프롬프트 복원기**
- `/prompt-restorer`

## 창 구성
- **확장 저장소**: 이 확장이 보낼 때마다 저장한 기록. 스와이프·재생성·이어쓰기가 각각 남습니다.
- **ST 기본 저장소**: SillyTavern이 직접 저장한 기록(메시지당 하나, 읽기 전용). "확장 저장소로 복사"로 옮겨 둘 수 있습니다.
- **월드인포 백업**: 지운 북·엔트리. 보기, 복사, .json 받기, 다시 넣기(엔트리는 넣을 북 선택, 북은 같은 이름이 있으면 "(복원 …)" 이름으로).

채팅을 고른 뒤 **마지막 프롬프트 / 세부 정보 / 전체 기록** 중 하나를 고릅니다. 전체 기록은 메시지 번호별로 묶인 타임라인이고, 각 기록에서 보기·복사·.txt·.json·.jsonl·삭제를 할 수 있습니다.

보기 창에서는 ◀ ▶(또는 방향키)로 기록을 넘기고, 복사가 막힌 브라우저에서는 **텍스트 선택 모드**로 직접 선택할 수 있습니다.

## 저장 방식 (중복 제거)
프롬프트를 메시지·문단 단위 조각으로 나눠, 같은 조각은 한 번만 저장합니다. 리롤·스와이프는 거의 공간을 쓰지 않고, 새 메시지를 보낼 때는 새로 생긴 부분만 늘어납니다. 3.0에서 저장한 기록은 처음 로드할 때 자동으로 바뀝니다.

## 설정 (서랍)
- 저장: 보내는 프롬프트 저장, 사칭·백그라운드 포함, 세부 정보 저장, 이미지 제외, 채팅당 최대 보관 개수
- 월드인포 백업: 켜기/끄기, 보관 기간(일)
- 화면: 테마, 페이지당 기록 수, 마법봉 바로가기, 현재 채팅 자동 선택
- 저장소 상태(원래 크기 → 실제 사용), 영구 보존 요청, 현재 채팅 점검, 목록 재구성, 프롬프트 기록 비우기
